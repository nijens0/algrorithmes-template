# C++ Algorithm Template

A clean, macro-free C++ template for competitive programming and algorithmic problem-solving.

## Features
* **Full standard library access** via `<bits/stdc++.h>`
* **Fast I/O** (`sync_with_stdio(false)` and `cin.tie(nullptr)`)
* **Standard constants** (`INF`, `LINF`, `MOD`)
* **Readable code** without custom macros or type aliases
